# Test rules

- Tests before or alongside code. A REQ without a test is not done. Mark: `@pytest.mark.req("REQ-021")` / `describe("REQ-021", ...)`.
- Layout: `api/tests/golden/` (register integrity, `test_vectors.py` parametrised over the 139 in-scope golden vectors only, none skipped; a calc whose WP has not merged is `xfail(strict=True)` naming that WP; the 16 vectors of the 14 OMITTED v0.3 calcs carry the marker `omitted_v03`, are deselected here and run only in `engineering/reference_calcs.py` (155/155 PASS); the Code Review P0 rule "vector skipped/xfailed without owner" exempts `omitted_v03`), `api/tests/contract/CON-xx/` (recorded cassettes), `api/tests/security/` (RBAC product x market scope matrix, HMAC, maker-checker, second-person kill switch, L2 stripping, SSRF, prompt injection, MCP read-only), `api/tests/<context>/` (unit + API), `web/tests/e2e/` (Playwright: login+MFA, P&L drilldown, COGS conflict, maker != checker approval, kill switch; v0.2: B2B maker != checker post, unified filters, Compat <-> CM toggle, five mobile journeys at 390x844), `web/tests/a11y/` (axe on every in-scope route — omitted marketing screens have no route — mobile and desktop viewports).
- Hypothesis invariants are named `test_invariant_<name>`: allocation conservation, ratio-of-sums margin, FIFO non-negative remaining, FX round-trip, null propagation, unclassified included in totals, period-close immutability, bounds never bypassed, ingest idempotent; v0.2: refund principal single-count, compat == CM net profit, CGST = SGST, posted B2B immutable, B2B sale counted once, intercompany eliminated once; v0.3: marketplace-facilitator tax nets to zero (CALC-113), channel fee conservation with Unclassified (CALC-114), ad spend never dropped, region isolation of rate limits; v0.3 rev 2: ad spend counted once per account under `spend_source` (`test_invariant_ad_spend_single_source`, GV-155).
- No network: `conftest.py` disables sockets. Cassettes are post-processed to synthetic IDs and amounts; `python api/tests/contract/scan_cassettes.py` runs in CI and fails on Amazon order-id, ASIN, e-mail, Bearer/token, GSTIN or real store-domain patterns; it allow-lists only `B0SYNTH\d{3}`, `SYNTH` GSTINs and `@example.test`, and also scans fixtures, `docs/`, `prompts/*.md` and `prompts/.claude/rules/*.md`.
- Fixtures are synthetic: no real order IDs, e-mails, tokens, account numbers.
- Migrations: CI runs `upgrade head`, `downgrade -1`, `upgrade head`; `alembic heads` must equal 1.
- Coverage gates (spec §9.4): `app/ledger`, `app/costing`, `app/profit`, `app/automation`, `app/b2b`, `app/tax` 90 % lines; all other packages 80 %; web 75 %.
- Schemathesis runs against `/api/v1/openapi.json`; every error must match the envelope.
- Never edit `engineering/golden_vectors.json` or `scope_register.json` to make a test pass; raise a change-control entry (WP-30).
